# 梨小食心虫积温模型参考笔记（任务二：虫害风险模块）

> 供实现者参考的文献口径整理。**实现时参数写入 index.html 参数区并注明出处；界面口径与本文一致；本地差异靠科技小院诱捕数据校准。**

## 模型框架（多机构交叉确认）

- **发育起点温度**：45℉ = **7.2℃**（UC IPM、Cornell NEWA、WSU、MSU、NC State、Virginia Tech 一致采用）
- **Biofix（起始锚点）**：诱捕器首次持续诱到雄成虫之日。本站无诱捕器数据，**以盛花日作为代理锚点**（盛花前后为越冬代成虫活动期），界面上注明"以盛花为代理锚点，建议结合诱捕器校准"
- **世代数**：温暖地区一季 4–5 代；本站按北方桃园常用前 3 代给出窗口

## 关键积温节点（DD，base 7.2℃，自 biofix 起算）

| 节点 | 积温值 | 含义 |
|---|---|---|
| 第 1 代产卵/孵化始期 | ~175 DD | 第一轮防治窗口 |
| 第 1 代后期 | ~350–375 DD | 第二轮窗口（重压园） |
| 第 2 代 | ~750 DD | 第二代窗口 |
| 第 3 代 | ~1400 DD | 第三代窗口 |
| 此后各代 | 每隔 ~500–560 DD | 温暖年后续代 |

## 蚜虫（粗判）

- 物候期口径：展叶–新梢速长期（盛花后 ~2–6 周）为危害窗口，出现卷叶即需防治
- 不做积温细化，仅给物候期提示（来源：通用 IPM 指南）

## 实现要点（对应 TASKS.md 任务二）

1. 复用 `gddSeries(base=7.2)`；起始锚点用有效盛花日（**自动跟随任务一的物候人工修正**）
2. 防治窗口 = 积温跨越节点日的前后各 ~5 天；行动项进 `buildPlan()`（lv=yel），月历加「虫」标签（建议色 `#3f3f46`，图例同步）
3. 需要全年逐日 7.2℃ 基点积温：`arcDailyURL` 已取全年数据（现仅算 4.5 基点），在 `refreshAll` 的合并循环里同时累加 7.2 基点即可，无需新请求
4. 「科学依据」展开区写明上表出处与"代理锚点"局限；具体药剂听当地植保站
