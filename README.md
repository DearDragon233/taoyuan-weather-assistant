## 这是什么

一个单文件、零依赖的静态网页工具，把公开气象数据换算成桃农能直接执行的农事决策：

| 功能 | 说明 |
|---|---|
| 🧭 **农事推进方案** | 规则引擎把冻害/病害/采收/旱情四路信号合成按日期排序的行动清单，一键复制发微信群 |
| ❄️ **花期冻害预警** | 物候积温推算花芽阶段 × 阶段临界温度表 × 16 天预报 → 红黄绿灯 + 熏烟/灌水等具体动作 |
| 😴 **休眠期低温监测** | 累计 0–7.2℃ 小时数对照品种需冷量，暖冬年提前提示萌芽不齐风险 |
| 📅 **采收窗口预测** | 盛花日估算 + 11 个品种发育期 → 各品种采摘日历（甘特图）+ 降雨窗口择晴采收 |
| 🦠 **病害风险日历** | 褐腐/缩叶/疮痂三种病害的侵染气象条件逐日判定，提示打药窗口 |
| 💧 **浇水决策** | 近 30 天降雨 − 桃树蒸散需水（ET₀×Kc）= 水分盈亏，结合 7 天降雨预报定浇不浇、补多少 |
| ✂️ **疏果套袋提醒** | 盛花 +25/35/56 天三个节点自动排进推进方案与月历 |
| 🗓 **农事月历** | 整月视图 + 事件标签 + 跨月翻页 + 月度统计 |

覆盖平谷 10 个主产乡镇（大华山、刘家店、峪口、王辛庄、山东庄、南独乐河、金海湖、镇罗营、黄松峪、城区），数据每 30 分钟自动更新。

## 快速开始

**桃农**：手机浏览器打开 <https://taoyuan-weather.pages.dev/>，选好所在的乡镇即可。无需注册、无需安装、不收集任何信息。

**开发者**：

```bash
git clone https://github.com/DearDragon233/taoyuan-weather-assistant.git
# 无构建步骤——直接用浏览器打开 index.html，或
npx serve .   # 本地预览
```

**部署自己的实例**：把 `index.html` 拖入 [Cloudflare Pages](https://pages.cloudflare.com/)（免费、无限带宽），或任意静态托管。

## 技术要点

- **数据源**：[Open-Meteo](https://open-meteo.com/) 开放接口（预报/历史归档/小时级，免注册，CORS 开放），前端直连、带 3 次退避重试与历史数据兜底
- **模型参数**：花芽冻害临界温度（Penn State Ext./WSU 1989 + 湖北省农业农村厅双口径）、品种需冷量与果实发育期（《果树栽培实用新技术》等文献）、病害侵染气象条件（PNW 手册/Texas A&M）
- **零依赖**：原生 HTML/CSS/JS 单文件，SVG 图表手绘，移动端优先适配（触控目标 ≥44px、安全区、汉堡抽屉导航）

## 项目背景

中国农业大学「种质环境适配与智能模型」暑期实践的延伸成果：实践队驻平谷区峪口镇调研时发现桃农面临霜冻无预警、采收靠经验、打药看邻居的普遍困境，遂将团队的机器学习方法论降维为这个零门槛的决策工具。开发：**彭宇程**（未来技术学院强基计划生物育种专业）。
